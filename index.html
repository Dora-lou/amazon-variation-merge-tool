Amazon Variation Tool

亚马逊变体合并工具

把已经上架的独立子 ASIN 合并到一个新建父体。不需要重新创建子体。

① 上传模板对应类目的 Excel
② 填父子体SKU、ASIN、变体属性
③ 下载文件上传亚马逊检查结果

第 1 步 上传亚马逊类目模板

选择你从亚马逊后台下载的原始类目模板，例如 ANIMAL_SHELTER.xlsm（户外猫屋）。

第 2 步 填写父体和子体信息

标有 * 的内容需要填写；已经存在的子体必须使用原 SKU 和原 ASIN。

A. 新建父体

必须是店铺中未使用过的 SKU；子体会自动关联它。

例如 Color 或 Color/Size，需符合该类目允许的变体主题。

B. 新父体描述与卖点（填写 1–5 条）

请填写你自己的父体商品描述，以及 1–5 条卖点。卖点只需要填写实际使用的条数，其余留空即可；不会覆盖已有子体的文案。

已填写 0 / 5 条卖点（至少填写 1 条）。

C. 已有独立子体

每行填写 1 个现有商品，颜色/尺寸等属性必须对应真实产品。

默认提供 10 行子体填写位置，空白行不会导出。

程序自动填：父体/子体关系、子体 Parent SKU、Product ID Type = ASIN，以及父体 Full Update / 子体 Partial Update。
高级设置：查看自动字段或修改类目属性

变体属性对应列（通常无需操作）

当颜色或尺寸列识别错误时，才需要手动改这里。

其他商品属性（原产地、电池、危险品等）

只在类目要求时补充。原产地、电池及危险品信息请确认与真实商品一致。

复用样例字段 / 特殊类目字段（谨慎使用）

默认关闭，避免把样例的旧商品属性带入其他商品。

第 3 步 检查并下载亚马逊上传表

下载前自动检查父体描述和五点是否都已填写，并防止亚马逊模板示例文案混入上传表格。

生成前会自动检查缺失信息、重复 SKU、重复属性组合以及父子 SKU 关系。

下载后，在亚马逊后台上传库存文件，检查处理报告和实际变体关系；仅下载成功不代表合并成功。

第一次使用？查看 3 个常见问题

应该上传哪个模板？ 使用子体所属的亚马逊商品类目模板。不同类目的模板不一定相同。

需要填新 ASIN 吗？ 不需要。新建的是父体 SKU，子体填写现有 ASIN。

上传后如何判断成功？ 看亚马逊处理报告，并在管理库存确认父子关系。若子体属于旧父体，可能需先处理旧关联。
