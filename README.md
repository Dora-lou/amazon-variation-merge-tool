# 亚马逊运营工具箱

在线工具：https://dora-lou.github.io/amazon-variation-merge-tool/

目前主要模块：

- **知识库**：合并/拆分变体、FBA 发货 SOP 等。
- **运营工具中心**：变体合并和 Listing 修改，生成 Excel 上传文件。
- **商品库**：本浏览器保存 Listing ASIN/MSKU、清货计费资料与库存、类目模板；支持 ZIP 备份与恢复。
- **AI Skills**：集中展示 Codex 技能，目前收录销售计划 Skill，提供启动指令及 Skill 文件链接。
- **Niche 数据提取**：按产品管理多个 Niche，上传 Product 与 Search Term CSV 后自动计算并导出一个多 Sheet Excel 工作簿。
- **SQR 搜索查询分析**：上传 Amazon Search Query Performance CSV，分析搜索词漏斗与 ASIN 份额。
- **清货与移除费用计算器**：导入父/子 ASIN、领星毛重、包装尺寸、ASP 和 FBA/AWD 五项库存，自动汇总库存并估算批量清货、移除退回和弃置费用。

旧版 **AI Agent** 入口已从导航和首页移除，相关代码保留在仓库中供未来参考，不再作为日常推荐入口。

## 旧版销售计划 Agent（保留代码，非推荐入口）

1. 下载整个项目代码。在需要运行 Agent 的 Windows 电脑上安装 Python 3.10+、Codex CLI、飞书 CLI 并配置有权使用的领星 MCP。
2. 确认安装 `feishu-amazon-sales-plan` Skill。仓库 `agent/skills/` 附带通用版本；如已有个人维护的同名 Skill，不要直接覆盖。
3. 双击 `agent/start-agent.bat`，将终端显示的随机配对码填入 [销售计划 Agent 页面](https://dora-lou.github.io/amazon-variation-merge-tool/agent.html)。
4. 选择 ASIN、月份和消化目标，点击「生成只读预览」。

详细配置、环境约束和测试请阅读 [agent/README.md](agent/README.md)。

## 重要提醒

- 商品库和类目模板保存在当前浏览器；换电脑需迁移有权保留的 ZIP 备份。
- AI Agent 运行在本机，代码可迁移；新电脑须重新安装本机环境并授权领星和飞书。
- Agent 服务只监听 `127.0.0.1`，不应开放到公网。配对码不能用于登录领星/飞书。
- 商品经营数据和任何 Token/Secret 都不应提交至公共 GitHub 仓库；离职后不得继续使用未经授权的公司数据或凭证。
- 只读预览不等于已完成库存口径验收：在途去重、成本缺失等问题须核对，正式表格写入功能尚未开放。


## Niche 数据提取

- 每个 Niche 单独上传后台导出的 Product CSV 与 Search Term CSV。
- 系统自动识别 CSV 表头、汇总 Total Clicks，并按搜索量 × 搜索转化率估算 Orders。
- 同一产品下可保存多个 Niche；重新上传同名 Niche 时仅覆盖该 Niche，其他 Niche 保留。
- 导出时，一个产品生成一个 Excel 工作簿，每个 Niche 对应一个 Sheet。
- 工作簿第一个 Sheet 为「总表」，汇集该产品所有 Niche 的搜索词；相同搜索词在不同 Niche 中分别保留。
- 总表按搜索量（过去 360 天）从高到低排序，第一列标注所属 Niche，并为不同 Niche 使用不同颜色；开启 Excel 自动筛选，可通过所属 Niche 下拉筛选市场。
- 每个 Sheet 的字段顺序固定为：搜索词、搜索量（过去 360 天）、CVR、Clicks、Orders%、Orders；其后保留原始 Search Term 表中的其他全部字段，并沿用原表字段顺序。
- Excel 使用统一的标题区、核心指标卡片、分组表头、交替行底色、数字格式、筛选和冻结窗格。
- 更新前已保存的旧版 Niche 没有保存原始 ST 其他字段；如需补齐，请重新上传该 Niche 的 Product CSV 和 Search Term CSV。
- 数据保存在当前浏览器的 IndexedDB 中；不调用 AI API，也不会将原始 CSV 上传到服务器。不同浏览器或设备之间不会自动同步。
- 当前版本暂不处理 SQR。



## FBA 清货与移除费用计算器

- 在运营工具中心打开「清货与移除费用计算器」。
- 商品资料 Excel/CSV 必须按固定列顺序提供 12 列：父ASIN、子ASIN、毛重、长、宽、高、ASP、FBA可售、FBA待调仓、FBA实际在途、AWD可用、AWD标发在途；每行对应一个子 ASIN。
- 毛重必须来自领星商品信息的「毛重」字段，单位 lb；长宽高必须是商品包装尺寸，单位 in；ASP 使用 USD。
- 库存直接从 Excel 导入，分别保留 FBA 可售、FBA 待调仓、FBA 实际在途、AWD 可用、AWD 标发在途；无库存填写 0，必须为非负整数，总库存为五项相加。
- 同一父 ASIN + 子 ASIN 再次导入时，商品基础数据和五项库存均以本次表格为准；未出现在本次文件中的旧商品记录会保留。
- 总库存 = FBA 可售 + FBA 待调仓 + FBA 实际在途 + AWD 可用 + AWD 标发在途。清货、移除和弃置费用只按 FBA 三项库存估算；AWD 两项计入总库存，但单独展示，不计入当前 FBA 处理费用。
- 尺寸等级根据包装尺寸和毛重自动估算；特殊处理属性无法仅凭尺寸识别。
- 第一版计费重量直接使用领星毛重，不额外进位、不计算体积重。清货展示 5%/10% 回收比例，按 15% 销售佣金和清货处理费计算净回款。
- 移除退回与弃置按当前内置 Removal/Disposal 费率计算；两者现金费用相同，但退回后保留商品、弃置不保留。
- 数据保存在与商品库共用的当前浏览器 IndexedDB 中，并纳入商品库 ZIP 完整备份；不调用 AI API，也不上传商品资料。
- 费用费率与尺寸判定规则可能随亚马逊政策变化，使用前应核对最新后台费率。

## SQR 搜索查询分析

- 在运营工具中心独立打开「SQR 搜索查询分析」，上传 Amazon 后台原始 Search Query Performance CSV。
- 自动读取报告元数据（ASIN、报告范围、年份、季度）与搜索查询数据；当前按后台 34 列季度报告格式识别。
- 本地计算报告所含搜索词的汇总数据、ASIN 曝光/点击/加购/购买份额、ASIN 点击率及加购/购买转化指标。
- 高需求词按当前报告搜索查询量第 75 百分位识别；高需求低曝光词指搜索量达到该阈值且该词 ASIN 曝光份额低于本报告加权 ASIN 曝光份额。
- 漏斗阶段份额指数为下一阶段 ASIN 份额除以上一阶段 ASIN 份额；低于 0.80 标记为份额流失，高于 1.20 标记为份额提升。这些是筛选指标，不代表因果结论。
- 搜索词会按折叠功能、外出场景、品类泛词、相邻产品形态、跨品类等文本规则分组，并给出相关性预判、样本提示、行动优先级和漏斗问题；分组不是亚马逊官方分类，需人工核对产品适配性。
- 关键词分组 Sheet 同时展示搜索量贡献占比和 ASIN 订单贡献占比，帮助区分“大流量低成交”和“低流量高贡献”词群。
- 导出工作簿共五个 Sheet，第一张为「SQR」胜率对比表，按用户提供的模板结构保留 10 个计算字段（类目点击率、ASIN点击率、点击胜率、类目-加购率、ASIN-加购率、加购胜率、类目-CVR、ASIN-CVR、CVR胜率、PRI）及后台 34 个原始字段；点击、加购、CVR 三项中，ASIN 指标高于类目时，对应胜率单元格以绿色标记。搜索词按搜索查询量从高到低排列。后续依次为「SQR总览」「搜索词分析」「关键词分组」「原始数据」，原始数据 Sheet 保留后台全部原始字段及原始行顺序。
- CSV 解析、计算和 Excel 导出均在浏览器本地完成，不调用 AI API，也不上传原始数据。
