# 亚马逊运营工具箱

在线工具：https://dora-lou.github.io/amazon-variation-merge-tool/

新手建议先阅读网页内的「使用说明.txt」；也可以在这里查看核心操作：

- **合并变体**：把两个或更多独立子体合并到一个新父体。
- **修改商品信息**：选择类目模板，搜索父 ASIN，再按子 ASIN 勾选商品：单个 MSKU 自动选定，多个 MSKU 手动选一个。
- **资料库**：保存类目模板和父 ASIN / 子 ASIN / 多个 MSKU 对应关系，支持领星表格导入、追加更新或完全替换。
- **备份与恢复**：下载完整 ZIP，备份商品库和所有类目模板；恢复会整体替换当前资料。

## 重要提醒

- 修改 Listing 时，只有勾选的字段会被写入上传表；一次选择多个子体时，相同内容会应用到所有已选商品。
- 商品库和类目模板保存在当前浏览器，不会自动同步到其他设备。更换电脑或清理浏览器数据前，先下载完整 ZIP 备份。
- 工具只生成 Excel，不会替你上传到亚马逊。上传后要查看处理报告，确认成功后再检查前台结果。
