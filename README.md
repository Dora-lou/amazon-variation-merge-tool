# 亚马逊运营工具箱

在线工具：https://dora-lou.github.io/amazon-variation-merge-tool/

程序分为三个模块：

- **知识库**：集中查看合并变体、拆分变体等后台操作步骤和 Case 文案。
- **表格自动生成工具**：包含「合并变体」和「修改 Listing」，生成亚马逊 Excel 上传文件。
- **商品库**：统一保存类目模板、父 ASIN / 子 ASIN / MSKU 对应关系，支持领星表格导入、追加更新、完全替换，以及完整 ZIP 备份与恢复。

## 重要提醒

- 修改 Listing 时，只有勾选的字段会被写入上传表；一次选择多个子体时，相同内容会应用到所有已选商品。
- 商品库和类目模板保存在当前浏览器，不会自动同步到其他设备。更换电脑或清理浏览器数据前，先下载完整 ZIP 备份。
- 工具只生成 Excel，不会替你上传到亚马逊。上传后要查看处理报告，确认成功后再检查前台结果。
