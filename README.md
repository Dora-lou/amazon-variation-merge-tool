# 亚马逊运营工具箱

**在线网页：** https://dora-lou.github.io/amazon-variation-merge-tool/

本项目包含两个模块，Excel 文件在浏览器本地处理，不登录亚马逊，也不会上传到网站服务器。

## 1. 合并变体
1. 从卖家后台下载对应类目的空白 .xlsx / .xlsm 模板。
2. 填写新父体信息、1–5 条卖点、变体主题，以及现有子体的原 SKU、ASIN 和变体属性。
3. 下载生成的表格，上传到亚马逊并检查处理报告。

## 2. Listing 修改
1. 每个类目首次上传亚马逊原始模板并保存分类名称，后续可直接选择已保存模板。
2. 在「商品资料库 / 历史记录」上传商品资料 Excel（.xlsx、.xls、.xlsm 或 .csv），至少包含父 ASIN、子 ASIN、SKU。程序自动识别表头，统计父体和子体数量，并显示预览供确认。
3. 如果商品资料没有类目列，可在导入页面指定默认分类（默认「户外猫屋」）；有类目列时会读取表格中的类目。品牌、父 SKU、标题、颜色、尺寸等列均可选。
4. 确认导入后，按父 ASIN 归组并保存子 ASIN/SKU 对应关系。重复导入会更新匹配到的子体并保留该组里未出现在新文件中的旧子体；如检测到一个子 ASIN 对应多个父 ASIN 或 SKU 冲突，会停止导入并提示。
5. 选择父 ASIN 后，可全选子体或手动勾选部分子体。商品分类会用于自动匹配对应类目模板。
6. 勾选需要修改的字段后才显示输入框，支持标题、五点、商品描述、Search Terms、普通售价，以及其他类目字段。
7. 现有 Listing 输出行包含身份字段：Product Type、Listing Action（Edit (Partial Update)）、Seller SKU、Product Id Type（ASIN）、Product Id（目标子 ASIN）、Brand Name；另外只写入本次选择的修改字段。
8. 五点默认 5 条；需要第 6 条及更多时点击添加，程序会在模板中插入列并调整技术字段编号。

## 资料保存与隐私
- 商品资料、类目模板和修改历史保存在当前浏览器的 IndexedDB 中，不会自动跨电脑同步。
- 浏览器资料库不会主动过期，但清理浏览器数据、换设备或使用无痕窗口可能导致无法访问；建议定期导出 ZIP 备份。
- 可以在「商品资料库 / 历史记录」中导出 ZIP 备份，并在另一台电脑或清理数据后恢复。
- 程序不会自动读取卖家后台数据。父 ASIN、子 ASIN、SKU 和品牌需要首次手动录入或从表格导入。
- 不从模板示例或其他店铺资料自动猜品牌；商品组缺少品牌时，生成 Listing 文件前会提示补充。
- 修改历史记录本次生成的目标商品和字段内容，不会自动读取亚马逊在线 Listing 的旧值。

## 重要提醒
- 上传模板应来自对应亚马逊类目；不同类目的字段和要求可能不同。
- 普通 Listing 属性修改不应顺手改写 Parentage Level、Parent SKU、Variation Theme 等变体关系字段。
- 生成文件不代表亚马逊已成功处理，最终以处理报告和实际前台结果为准。
- 五点描述扩展到 5 条以上时，请特别检查新增列的字段编号及生成文件结构。
