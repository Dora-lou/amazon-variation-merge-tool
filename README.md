# 亚马逊变体合并工具

**使用网页：** https://dora-lou.github.io/amazon-variation-merge-tool/

**简短说明：** [使用说明.txt](./使用说明.txt)

工具用途：新建一个父体，将多个已上架的独立子 ASIN 合并为一个变体家庭。

1. 从亚马逊后台下载**对应类目的空白 Excel 模板**，上传到网页。
2. 填写新父体信息、1–5 条卖点、变体主题，以及各子体原 SKU、ASIN 和变体属性。
3. 下载生成的表格并上传至亚马逊，检查处理报告。

**原理：** 新父体使用 Full Update，已有子体使用 Partial Update；子体的 Parent SKU 指向新父 SKU，关联相同的变体主题。

注意：若子体属于其他父体，需要先解除旧关系；是否合并成功以亚马逊处理报告及实际变体关系为准。
