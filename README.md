# 亚马逊变体合并工具｜使用说明

**打开网页：** https://dora-lou.github.io/amazon-variation-merge-tool/

**用途：** 新建 1 个父体，把店铺内已经上架的多个独立子 ASIN 合并到该父体下。程序只负责生成亚马逊上传模板，不会直接修改卖家后台。

## 使用方法（3 步）

1. **上传类目模板**：从亚马逊卖家后台下载对应商品类目的 Excel 模板（`.xlsm` / `.xlsx`），拖入或选择文件。猫屋、加热垫、围栏的模板可能不同，请使用对应类目。
2. **填写合并信息**：填写新的**父 SKU**、**父体标题**、品牌（若未自动带出）、**变体主题**，还需要填写**新父体的英文商品描述及五点卖点**。支持直接粘贴你自己准备的产品文案，程序不会自动编造或替换内容。子体表格里填写每个已上架商品的**原 SKU、ASIN、颜色/尺寸等变体属性**。默认显示 **10 行子体填写位置**，不够可点「添加 1 行 / 添加 5 行」，未填写的空行不会导出。如果已有样例数据，先核对并替换，避免沿用旧商品。
3. **生成并上传**：程序会检查父体描述和五点必填、排除亚马逊模板示例文案；通过后点击「检查并下载 Excel」，将生成文件上传至亚马逊卖家后台的库存文件上传入口，并检查**处理报告**和后台父子体关系。

## 哪些字段不用手动填？

| 字段 | 处理方式 |
| --- | --- |
| Product Type | 尽可能从类目模板识别 |
| Listing Action | 父体 Full Update，子体 Partial Update |
| Parentage Level | 父体 Parent，子体 Child |
| Parent SKU | 每个子体自动引用新父 SKU |
| Product ID Type | 子体自动填 ASIN；父体留空 |
| Item Type Keyword | 模板仅有一个选项时自动选定；有多个时须确认 |
| Country of Origin / Batteries / Hazardous Goods | 可用模板默认值或人工确认后修改 |

**示例：** 父 SKU = `CAT-HOUSE-PARENT`；子体保留原 SKU（如 `CAT-GREY-S`）、原 ASIN，再填写对应颜色和尺寸。

## 使用前注意

- 只适用于符合亚马逊类目变体政策、属性主题一致的商品；合并不等于审核一定通过。
- 请先检查子 ASIN 是否属于其他变体家庭，必要时先处理旧父子关系。
- 在首次使用不同类目时，建议先小批量上传测试，并检查库存文件处理报告。
- 请不要将成功案例里的旧子体 SKU、ASIN、标题直接用于其他商品。**亚马逊模板自带的鞋子/服饰示例描述、五点不可用于真实商品。**
- 网页在浏览器中处理 Excel，不要求上传商品数据到网站服务器；代码公开可查看，但不要把含真实经营信息的 Excel 上传到公开 GitHub 仓库。
- 下载文件成功**不代表亚马逊已经接受变体合并**，以后台处理报告和实际父子关系为准。

有问题时，可把报错文字或生成的文件提供给工具维护者检查。
