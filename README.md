# 亚马逊运营工具箱

**在线工具：** https://dora-lou.github.io/amazon-variation-merge-tool/

Excel 文件在浏览器本地处理，不登录亚马逊，也不会上传到网站服务器。

## 主要模块

### 1. 合并变体
从亚马逊后台下载对应类目的空白 Excel 模板，填写新父体信息及已有子体的原 SKU、ASIN 和变体属性，生成上传文件。

### 2. 修改商品信息
选择类目模板、搜索父 ASIN，再选择全部或部分子 ASIN。生成文件时，程序按子 ASIN 自动匹配 SKU；选择标题、五点、描述、亮点、价格、Search Terms 或其他需要修改的字段后生成上传表。

### 3. 类目模板库
保存类目名称和对应的亚马逊空白类目模板。同名类目可以上传新版本替换旧模板。

### 4. 商品库
保存父 ASIN、子 ASIN、SKU 的对应关系。支持手动维护，或导入 Excel / CSV；导入表格至少包含父 ASIN、子 ASIN、SKU 三列。程序会检查重复或冲突的映射。

## 数据保存
- 类目模板和商品库保存在当前浏览器的 IndexedDB 中，不会自动跨电脑同步。
- 可通过 ZIP 备份迁移或恢复类目模板和商品库。
- 清理浏览器数据、使用无痕窗口或更换设备前，请先导出备份。

## 注意事项
- 类目模板应来自对应的亚马逊类目；不同类目的字段要求可能不同。
- 普通 Listing 修改只写入身份字段和本次选择的修改字段，不应意外改动 Parentage Level、Parent SKU、Variation Theme 等变体关系字段。
- 生成文件不代表亚马逊已成功处理，最终以处理报告和实际 Listing 结果为准。
