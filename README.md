# 亚马逊运营工具箱

在线工具：https://dora-lou.github.io/amazon-variation-merge-tool/

## 商品库

商品库分为三个模块：

1. **导入商品**：可以手动添加单个商品组，或上传 Excel / CSV 批量导入；也支持粘贴表格内容。
2. **已保存商品**：可搜索父 ASIN、编辑或删除商品组，每页最多显示 5 个父 ASIN；也可单独下载商品库 CSV。
3. **资料库备份与恢复**：一键下载完整 ZIP，包含商品库、全部类目模板文件、manifest.json 和可用 Excel 打开的 products.csv。

## 完整备份与恢复

- 备份 ZIP 包含商品库记录和类目模板文件，适合更换电脑或恢复浏览器资料。
- 恢复时选择 ZIP 并点击「上传并恢复全部资料」。程序会先检查备份，再要求确认。
- **完整恢复会整体替换当前商品库和类目模板**，当前未包含在备份里的内容会被覆盖。建议恢复前先下载当前 ZIP。
- CSV 只包含父 ASIN、子 ASIN、SKU 对应关系，不包含类目模板文件。

## 数据保存

- 商品库和类目模板保存在当前浏览器的 IndexedDB 中，不会自动跨电脑同步。
- Excel 在浏览器本地处理，不会上传到网站服务器。
- 清理浏览器数据或更换设备前，请下载完整 ZIP 备份。

## Listing 修改与变体合并

- 修改商品信息时选择类目模板、搜索父 ASIN，再勾选全部或部分子 ASIN。生成文件时会自动按子 ASIN 匹配 SKU。
- 变体合并需要上传对应类目的亚马逊空白模板。
- 生成文件不代表亚马逊已成功处理，最终以处理报告和前台结果为准。
