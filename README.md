# 亚马逊运营工具箱

**在线网页：** https://dora-lou.github.io/amazon-variation-merge-tool/

本项目包含两个模块，Excel 文件在浏览器本地处理，不登录亚马逊，也不会上传到网站服务器。

## 1. 合并变体
1. 从卖家后台下载对应类目的空白 .xlsx / .xlsm 模板。
2. 填写新父体信息、1–5 条卖点、变体主题，以及现有子体的原 SKU、ASIN 和变体属性。
3. 下载生成的表格，上传到亚马逊并检查处理报告。

新父体使用 Full Update，已有子体使用 Partial Update；子体的 Parent SKU 指向新父 SKU。若子体属于其他父体，需要先解除旧关系。

## 2. Listing 修改
从顶部导航进入 **Listing 修改**：
1. 每个类目首次上传亚马逊原始模板并保存分类名称，后续可直接选择已保存模板。
2. 在商品资料库录入或批量导入商品组，保存父 ASIN、子 ASIN、SKU 和真实 Brand Name。选择父 ASIN 后，可勾选全部子体或只更新指定子体。
3. 勾选需要修改的字段后才显示对应输入框，支持标题、五点、商品描述、Search Terms、普通售价，以及其他类目字段。
4. 现有 Listing 的输出行包含识别和更新所需的身份字段：Product Type、Listing Action（Edit (Partial Update)）、Seller SKU、Product Id Type（ASIN）、Product Id（目标子 ASIN）、Brand Name；另外只写入用户选择修改的字段。
5. 五点勾选后显示 5 个输入框；需要第 6 条及更多时点击添加，程序会在模板中插入列并调整技术字段编号。
6. 生成后先检查 Excel，再上传到亚马逊并查看处理报告。

## 资料保存与隐私
- 商品资料、类目模板和修改历史保存在当前浏览器的 IndexedDB 中，不会自动跨电脑同步。
- 可以在「商品资料库 / 历史记录」中导出 ZIP 备份，并在另一台电脑或清理浏览器数据后恢复。
- 程序不会自动读取卖家后台数据。父 ASIN、子 ASIN、SKU 和品牌需要首次手动录入或从表格导入。
- 不从模板示例或其他店铺资料自动猜品牌；每个商品组应保存实际的 Brand Name。
- 修改历史记录本次生成的目标商品和字段内容，不会自动读取亚马逊在线 Listing 的旧值。

## 重要提醒
- 上传模板应来自对应亚马逊类目；不同类目的字段和要求可能不同。
- 普通 Listing 属性修改不应顺手改写 Parentage Level、Parent SKU、Variation Theme 等变体关系字段；只有专门调整变体关系时才使用这些字段。
- 生成文件不代表亚马逊已成功处理，最终以处理报告和实际前台结果为准。
- 五点描述扩展到 5 条以上时，请特别检查新增列的字段编号及生成文件结构。
