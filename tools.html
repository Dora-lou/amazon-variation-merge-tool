表格自动生成工具

按任务选择对应工具。程序会读取你选择的亚马逊类目模板，按要求生成 Excel 上传文件；商品资料和类目模板统一在「商品库」维护。

选择要处理的任务

先选功能，再按页面步骤填写，不需要在一个页面里切换不同任务。

TOOL 01

合并变体

将多个已经独立上架的子体合并到一个新的父体下，生成对应的亚马逊 Excel 上传表格。

上传或选择类目空白模板填写父体、子体与变体属性检查并下载上传表格
打开合并变体工具→
TOOL 02

修改 Listing

批量修改已有商品的标题、五点、描述、亮点、价格等字段，只生成你勾选的内容。

选择类目模板按父 ASIN 选择商品并确认 MSKU填写字段并生成上传表格
打开 Listing 修改工具→
