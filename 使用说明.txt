亚马逊运营工具箱｜使用说明

【模块一：合并变体】
1. 从亚马逊卖家后台下载对应类目的空白 Excel 模板（.xlsx 或 .xlsm）。
2. 上传模板，填写新父 SKU、父体标题、品牌、商品描述、1–5 条卖点，并选择变体主题。
3. 填写各子体原 SKU、ASIN 及颜色、尺寸等变体属性。
4. 点击“检查并下载 Excel”，将生成的文件上传到亚马逊后台。
5. 查看上传处理报告，确认父子变体关系建立成功。

【模块二：Listing 修改】
1. 从顶部导航进入“Listing 修改”。
2. 第一次使用某个类目时，上传亚马逊原始模板并填写分类名称；模板会保存在当前浏览器，下次可以直接选择。
3. 在“商品资料库 / 历史记录”录入或批量导入商品组。每组保存父 ASIN、子 ASIN、子 SKU 和实际的 Brand Name。
4. 选择商品组/父 ASIN，并勾选需要更新的子体；可全选，也可只选单个子体。
5. 勾选标题、五点描述、商品描述、Search Terms、普通售价或其他类目字段后，对应输入框才会显示。可以一次选择多个字段。
6. 生成文件会包含必需的身份字段：Product Type、Listing Action = Edit (Partial Update)、Seller SKU、Product Id Type = ASIN、Product Id = 目标子 ASIN、Brand Name；其他 Listing 字段仅写入本次选中的内容。
7. 五点勾选后默认显示 5 条输入框。点击“添加下一条 Bullet Point”可添加第 6、7 条及更多；程序会尝试在模板中插入列并调整技术字段编号。
8. 生成后先检查 Excel，再上传亚马逊并查看处理报告。

【资料库、备份与恢复】
- 商品资料、模板和修改历史保存在当前浏览器，不会自动跨设备同步。
- 建议定期导出 ZIP 备份；更换电脑或清理浏览器数据后，可通过 ZIP 备份恢复。
- 程序不会自动读取卖家后台；ASIN/SKU/品牌需手动录入或导入。
- 不会从模板示例或其他店铺资料自动猜品牌，避免误用店铺品牌。

【注意事项】
- 子体若已属于其他父体，合并前须先解除旧关系。
- 普通 Listing 属性修改时，只使用 Listing Action = Edit (Partial Update) 并写入身份字段和本次选择的属性；不要意外改动 Parentage Level、Parent SKU、Variation Theme。
- 不同类目使用各自的亚马逊模板；新增字段或扩展五点后，务必检查表格结构。
- 下载成功不等于亚马逊上传成功，以处理报告和实际 Listing 结果为准。
- 本工具在浏览器本地处理 Excel，不登录亚马逊、不向网站服务器上传文件。
