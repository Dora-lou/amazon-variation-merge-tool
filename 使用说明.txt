亚马逊运营工具箱｜新手使用说明

一、先看你要做什么
- 合并变体：把几个原本独立的商品合并到一个新父体下。
- 修改商品信息：批量修改已有商品的标题、五点、描述、亮点、价格等。
- 资料库：保存常用的类目模板和商品对应关系。
- 备份与恢复：下载全部资料备份，或在需要时恢复资料。

二、第一次使用前，先准备资料

如果你要修改已有商品，建议先完成以下两步：

第一步：保存类目模板
1. 打开「Listing 修改与资料库」。
2. 进入「资料库」→「类目模板库」。
3. 填写容易辨认的类目名称，例如 Outdoor Cat House。
4. 上传从亚马逊卖家平台下载的、对应类目的空白 Excel 模板。
5. 点击「保存类目模板」。

以后修改同类商品时，可以直接选择已保存的模板，不用重复上传。

第二步：导入商品资料
1. 进入「资料库」→「商品库」。
2. 选择「手动添加」或「表格批量导入」。
3. 商品资料需要包含三项：父 ASIN、子 ASIN、MSKU（可以从领星导出）。同一子 ASIN 有多个 MSKU 时，可以在一个单元格中用逗号分隔。
4. 表格导入时，先点击「识别文件并统计」，检查结果无误后，再点击「确认导入并保存」。

商品库用于帮助程序找到正确的商品。修改 Listing 时，先选父 ASIN，再确认本次使用的 MSKU。

注意：如果你只是合并几个独立商品，可以直接进入「合并变体」，不需要先导入商品库。

三、如何合并变体
适用情况：几个商品已经分别上架，现在要把它们合并到一个新父体下。

第 1 步：选择模板
1. 打开「合并变体」。
2. 选择已保存的类目模板。
3. 如果没有合适的模板，展开「上传一个新模板」，上传对应类目的亚马逊空白 Excel。

第 2 步：填写新父体信息
1. 填写一个店铺从未使用过的父体 SKU。
2. 填写父体标题。
3. 选择变体主题，例如 Color 或 Color/Size。
4. 填写商品描述，并至少填写一条五点描述，最多可先填写五条。

文案请使用你自己的真实商品内容，不要直接保留模板中的示例文案。

第 3 步：填写子体信息
每个子体占一行，需要填写：
- 原有 SKU
- 原有子 ASIN
- 对应的颜色、尺寸等变体属性

SKU 和 ASIN 必须对应正确。需要增加子体时，点击「添加 1 行」或「添加 5 行」。

第 4 步：生成并上传
1. 点击「检查并下载 Excel」。
2. 如果提示错误，根据提示修改后重新生成。
3. 打开亚马逊卖家平台，进入库存文件上传入口。
4. 上传生成的 Excel。
5. 查看处理报告，并检查前台变体关系是否正确。

特别注意：此功能用于把独立子体合并到新父体，不需要搜索原父 ASIN。下载成功不代表合并成功，最终以亚马逊处理结果为准。

四、如何修改已有商品信息
适用情况：修改已经存在的商品，不需要重新创建父子体关系。

第 1 步：选择模板
1. 打开「Listing 修改与资料库」→「修改商品信息」。
2. 选择与商品所属类目对应的已保存模板。

第 2 步：选择商品
1. 输入需要修改的父 ASIN。
2. 从匹配结果中选择正确的父 ASIN。
3. 页面会显示该父体下的子体及 MSKU，默认全选。一个子 ASIN 只有一个 MSKU 时会自动选中；有多个时必须手动选择其中一个。
4. 取消勾选不需要修改的商品。未选择好 MSKU 的子体不能直接生成上传文件。

第 3 步：选择修改内容
勾选本次需要修改的字段，例如标题、商品描述、亮点或五点，再填写新内容。未勾选的字段不会主动写入上传表。

五点默认提供五条，需要更多条时可以点击「添加下一条 Bullet Point」。

如果需要修改售价、Search Terms 或其他类目属性，展开「其他类目字段（高级）」，选择字段、点击「添加字段」，再填写新值。

重要：每个被选中的子 ASIN 只使用你确认的一个 MSKU 生成上传表。一次选择多个子体时，相同修改内容会应用到所有选中商品；内容不同请分开生成。

第 4 步：生成并上传
1. 点击「检查并生成 Listing 上传表」。
2. 下载 Excel，检查本次选定的 MSKU、子 ASIN 和修改内容。
3. 上传到亚马逊卖家平台。
4. 查看处理报告，确认修改是否成功。

五、如何使用资料库

1. 类目模板库
用于保存不同类目的亚马逊空白模板。添加新模板时，填写类目名称并上传对应的 Excel 模板。同名类目可以用新模板替换旧模板。

2. 商品库
用于保存父 ASIN、子 ASIN 和一个或多个 MSKU 的对应关系。支持手动添加、Excel/CSV 批量导入、搜索父 ASIN、编辑和删除商品组。

同一个 MSKU 可以出现在不同父 ASIN 分组中。导入时可选择「追加/更新」或「完全替换商品库」，完全替换不会删除类目模板。不同子 ASIN 不能在同一父 ASIN 下共用相同 MSKU。

3. 资料库备份与恢复

备份：
1. 进入「资料库」→「商品库」下方的「资料库备份与恢复」。
2. 点击「一键下载全部资料（ZIP）」。
3. 保存下载的 ZIP 文件。它包含商品库（包括每个子 ASIN 的全部 MSKU）和所有已保存的类目模板。

恢复：
1. 选择之前下载的完整 ZIP 文件。
2. 点击「上传并恢复全部资料」。
3. 检查提示并确认恢复。

注意：恢复会整体替换当前商品库和类目模板。恢复前请先备份当前资料。

六、使用前必须知道
1. 商品库和类目模板保存在当前浏览器中，不会自动同步到其他电脑或浏览器。
2. 清理浏览器数据或更换电脑前，先下载完整 ZIP 备份。
3. 程序只负责生成 Excel，不会自动登录亚马逊或替你上传文件。
4. 上传后务必查看亚马逊处理报告，确认是否成功。
5. 遇到报错时，先根据提示检查模板、SKU、ASIN 和必填字段，不要直接忽略错误。
