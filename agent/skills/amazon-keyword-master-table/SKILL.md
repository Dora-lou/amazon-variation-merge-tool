# Amazon Keyword Master Table

## 目标

把一次“分析某个产品的关键词”固定为一条可复用、可追溯的链路：

`产品名称/ASIN/SKU → 产品身份确认 → 领星自有搜索词与出单词 → 西柚目标 ASIN/竞品关键词 → 相关性与证据分层 → 关键词总表 → 飞书电子表格回读校验`

每次运行都要同时交付两部分：

1. 飞书中的可继续维护的关键词研究总表。
2. 聊天中的简短交付摘要，说明产品身份、数据周期、来源覆盖、关键数量、缺口和表格链接/Token（若工具返回）。

## 触发与默认行为

- 用户只要说“分析某个产品”“做关键词总表”“研究出单词/竞品词/西柚词”，即进入本 Skill。用户不必重复说明要查领星和西柚。
- 输入可以是产品名称、父 ASIN、子 ASIN、SKU、MSKU 或已有飞书表格链接。优先复用用户提供的明确标识；只有名称时先做产品匹配，不要反复索要 ASIN。
- 关键词研究默认采用最近 **12 个完整自然月**作为长期研究周期；若领星或西柚只支持近 30 天/近 7 天，按工具实际返回周期记录，不把短周期冒充全年数据。用户指定周期时以用户为准。
- 站点优先使用用户明确指定的站点；否则从已确认的产品记录、ASIN 或飞书产品档案中推断。若同一名称对应多个站点或多个不确定产品，才暂停并询问。
- 默认在飞书 `至拓-运营` 中寻找已有产品档案、历史关键词表和可复用模板。若找到同一产品的旧表：用户说“更新/追加/补充”时更新该表；用户只说“分析”时新建一份版本表，保留旧表不覆盖。
- 不自动创建广告活动、不改预算/Bid、不执行否词；本 Skill 只研究、整理、提出投放承接建议。

## 数据来源与调用顺序

### 1. 先确认产品身份

先读取飞书中与产品相关的档案/历史表；没有明确记录时，用领星和西柚的只读能力匹配。建立并在总表 `总览`/`数据说明` 中记录：站点、父 ASIN、子 ASIN、SKU/MSKU、产品名称、研究主体、是否合并变体、排除的相邻产品/ASIN。

若输入的是子 ASIN，尽量补齐父 ASIN、同父体子 ASIN 和 SKU 映射；若用户明确只分析单个子体，不擅自扩展为父体。

### 2. 领星：自有搜索词与真实出单证据

领星使用 `mcp__yb_lingxing__help` → `mcp__yb_lingxing__search` → `mcp__yb_lingxing__action`。首次进入任务先用 `help` 搜索与“产品/ASIN/SKU/搜索词/广告搜索词/SP/报告”相关的工具，再按返回的真实 Schema 调用；禁止凭记忆猜字段或工具 ID。

优先获取：

- 目标父/子 ASIN 与 SKU 映射。
- SP 搜索词报告原始行：搜索词、曝光、点击、订单、直接/间接订单、花费、销售额、ACOS、CVR、报告周期和筛选条件。
- 订单大于 0 的真实出单词，并单独保留直接订单与间接订单。
- 如可用，再获取完整自然月的产品级销量/广告/自然订单用于季节性背景；这类产品级月份数据不能冒充关键词级搜索量。

领星返回空、报错或字段不足时，先在 `help` 中寻找同一字段的替代工具；只有相关替代接口也失败后，才把字段标记为“当前无法获取”。保留查询失败的工具、参数口径和原因。

### 3. 西柚：目标 ASIN 与强相关竞品关键词

西柚数据按“目标 ASIN 证据”和“竞品参考证据”分层，不把竞品词当成目标产品已经成交。

- 目标 ASIN：按实际可用工具获取 ASIN 关键词、关键词流量、自然/广告流量、覆盖子 ASIN、排名/趋势或 ABA/关键词指标。
- 竞品参考：先确定少量强相关竞品（形态、用途、物种/对象、核心功能和价格带可比），再读取竞品关键词/流量。排除目标 ASIN、弱可比产品、相邻功能产品和明显不同物种；不为了凑数量虚构竞品。
- 只在当前任务确实需要时读取 `get_asin_info`、`get_asin_variations`、`get_asin_keywords`、`get_asin_keyword_traffic_trends`、`get_multi_asin_keyword_comparison`、`find_keyword_opportunities` 等相应能力；不要无目的遍历全部西柚接口。
- 每次西柚工具调用都必须填写同一份用户原话 `user_task`，以及本次调用的简短 `intent_summary`；不要把子问题改写成新的用户任务。记录西柚返回的实际周期、口径、更新时间和费用/状态（如有）。

西柚流量、排名、相关性分数、ABA 周搜索量和 Niche 估算必须按原指标名记录。估算值标为估算；缺失值留空并写“待补采”，不得从相邻词、竞品或词根复制。

### 4. 历史词库与飞书资料

只有在资料确实属于目标产品、且能确认来源和周期时，才把历史词库的订单、花费、ACOS、CVR 等作为目标产品证据。猫屋、加热垫、狗类等相邻产品的资料可以保留为“相邻/排除证据”，不能混入目标产品表现。

## 关键词处理规则

先读现有 `amazon-sp-wordsea` 的相关参考文件，尤其是 `references/course-rules.md` 和 `references/workbook-schema.md`；本 Skill 负责编排来源与飞书落表，不重新发明课程中的拆词/拼词规则。

- 原始来源必须保留：每个来源词、原始拼写、来源 ASIN/报告、周期、指标和筛选条件进入原始或来源 Sheet。
- 标准化只用于匹配和去重：大小写、首尾空格和明显空白差异可生成 `标准化关键词`，但不删除原始记录，也不合并不同来源的指标为一个“虚构总量”。
- 相关性先于流量：依据已确认的产品形态、对象/物种、场景、属性、功能和用户意图分为目标相关、相邻参考、排除/非目标、待确认；说明理由。
- 证据层级至少区分：`领星真实出单`、`领星有点击无订单`、`西柚目标 ASIN 词`、`西柚竞品词`、`历史词库`、`待验证/AI 生成`。有出单不等于无条件进入主动池；还要经过相关性与用户设定的搜索量门槛。
- 关键词级 ABA/搜索量若有精确记录，按 `amazon-sp-wordsea` 的门槛规则处理；默认 ABA 周搜索量大于 1,000 的词保留在原始库和排除记录中，不放入受门槛约束的主动候选。用户明确改变门槛时，以本次用户要求为准并记录新门槛。
- 不能从词根、相关词、竞品流量或产品总流量推导关键词搜索量、订单、排名、CPC 或转化率。生成词若没有精确数据，标记为“AI 生成/待 ABA 验证”，不能写成已验证低量词。
- 默认不主动生成大量 AI 拼词；只有课程规则明确允许、每个组成词已审核且语义与产品成立时才生成，并在行内记录公式和组成词。

## 飞书总表结构

默认按 [master-table-schema.md](references/master-table-schema.md) 建表。最少应有：`总览`、`关键词总表`、`领星出单词`、`领星原始搜索词`、`西柚目标ASIN词流量`、`西柚竞品流量词`、`数据说明`。当数据支持时再增加 `竞品`、`词根与属性`、`流量结构`、`否词库`、`淡旺季分析` 等 Sheet；没有数据就不要创建空的分析页。

`关键词总表`按标准化关键词一行一词，至少包含：原词、标准化词、状态/相关性、关键词聚类与类型、领星订单/花费/销售额/ACOS/CVR/点击/曝光、西柚目标/竞品指标、ABA/Niche 口径、来源标记、数据周期、优先级、Listing 布局建议、广告匹配建议、数据缺口。

飞书写入遵循以下顺序：

1. 用 `lark-cli drive +search` 定位知识库/文件夹/旧表；若目标是电子表格，先用 `lark-cli sheets +workbook-info` 读取真实 Sheet 名和结构，不猜 `Sheet1`。
2. 新建表优先使用 `lark-cli sheets +workbook-create --sheets`；已有表只在用户要求更新/追加时修改，原始来源页不覆盖。新表可复制已验证模板的 Sheet 结构，但不能把旧产品指标带入新产品。
3. 写入量值数据时使用 `+table-put` 或 `+cells-set` 的类型保真方式；金额、比例、数量、日期不要先拼成文本。样式/合并/冻结/列宽使用 `+styles-put` 或相应原生能力。
4. 写入后必须回读 `+csv-get`/`+cells-get`，至少校验：标题、表头、数据首尾行、关键词去重、缺失值标记、源数据周期、ABA 门槛排除、总览统计和链接/Token。
5. 表格链接或 Token 只有在真实创建/写入并回读成功后才可在回复中声称已完成；失败时明确写出失败阶段与可继续的最小动作。

写表前先确定真实末行和目标范围；不要用清空、删除 Sheet、覆盖整表来“刷新”。对用户原有表格最小改动，默认新建版本表。

## 交付与质量检查

回复中分开写 `已确认事实`、`分析判断`、`待验证事项`，并至少包含：

- 产品身份与研究周期。
- 领星、西柚、历史词库各自实际查询到的来源和数据周期。
- 原始词数、去重后词数、真实出单词数、目标相关词数、排除词数、待验证词数。
- 关键词总表所在飞书表格和关键 Sheet。
- 任何未取得的 ABA、Niche、竞品、子 ASIN、历史周期或字段，以及这些缺口对结论的影响。

落表前逐项检查：

- 目标 ASIN 与子体映射没有混入其他产品。
- 原始来源行仍可追溯，竞品词没有被标记为目标产品出单词。
- 关键词总表没有同一标准化关键词重复行，除非是明确不同来源的原始 Sheet。
- 任何精确 ABA 大于门槛的词不在受门槛约束的主动候选中，但仍在原始/排除记录中。
- 缺失值没有被写成 0；生成词没有复制相邻词指标。
- 飞书写入已真实回读验证，报告的数量和表格内容一致。

若某一数据源不可用，仍可交付已取得来源的分层总表，但必须把未取到的来源放入 `数据说明`，降低结论强度，不因缺口中止全部工作。
