# 关键词研究总表：推荐结构

这是本 Skill 的默认落表结构。根据实际数据删减空的分析页，但不要删除来源追溯页。

## 1. 总览

建议字段：

`项目｜结果/数量｜数据口径｜处理说明`

至少记录研究主体、父/子 ASIN、站点、研究周期、领星周期、西柚周期、原始记录数、去重词数、真实出单词数、目标相关词数、排除词数、待验证数、ABA 门槛、竞品样本状态和主要缺口。

## 2. 关键词总表

一行一个标准化关键词。推荐字段如下，列顺序可按飞书模板调整，但不要丢失字段语义：

`关键词｜标准化关键词｜关键词状态｜关键词聚类｜关键词类型｜搜索意图/相关性｜相关性说明｜是否来自领星搜索词｜是否来自领星出单词｜是否来自西柚目标ASIN｜是否来自西柚竞品｜是否来自历史词库｜主要来源说明｜原始来源记录数｜数据周期｜自身订单｜自身直接订单｜自身间接订单｜自身花费｜自身销售额｜自身ACOS｜自身CVR｜自身点击｜自身曝光｜西柚目标ASIN流量｜西柚自然流量｜西柚广告流量｜西柚覆盖ASIN数｜西柚竞品流量｜ABA周搜索量｜ABA报告周｜Niche搜索量｜趋势/排名｜优先级｜Listing布局建议｜广告匹配方式建议｜投放建议｜数据完整度｜置信度｜数据缺口/备注`

原始数据不存在时留空并写明“待补采/当前接口无法确认”，不要填 0。目标 ASIN 与竞品指标分列；不把多个竞品估算流量简单相加为搜索量。

## 3. 领星出单词

建议字段：

`关键词｜订单｜直接订单｜间接订单｜花费｜销售额｜曝光｜点击｜ACOS｜CVR｜目标产品相关｜数据周期｜ASIN/SKU筛选｜来源`

该页只放领星原始/聚合后的真实出单记录；相关性筛选结果可加字段，但不要删除不相关原始词。

## 4. 领星原始搜索词

保留领星返回的原始字段和查询元数据。至少包含搜索词、曝光、点击、订单、直接/间接订单、花费、销售额、ACOS、CVR、报告周期、父/子 ASIN/SKU 筛选、抓取时间和来源工具。

## 5. 西柚目标ASIN词流量

建议字段：

`关键词｜中文释义（如有）｜总流量｜自然流量｜广告流量｜覆盖子ASIN数｜相关性/排名指标｜趋势状态｜周期｜返回日期｜来源`

## 6. 西柚竞品流量词

建议字段：

`关键词｜中文释义（如有）｜竞品总流量｜竞品自然流量｜竞品广告流量｜覆盖竞品ASIN数｜覆盖竞品ASIN｜相关性/排名指标｜周期｜用途`

用途默认写“竞品参考，不等同于目标产品出单或目标产品流量”。

## 7. 数据说明

建议字段：

`项目｜来源/工具｜查询条件｜实际数据周期｜指标口径｜处理方式｜缺口/限制`

把工具失败、空结果、权限不足、接口只支持短周期、目标 ASIN 未覆盖、ABA 未取得等事实写在这里。

## 8. 可选分析页

- `竞品`：只放已验证强相关竞品的 ASIN、品牌、标题、形态、价格、评分、评论、销量/销售额、流量结构和周期。
- `词根与属性`：只从目标产品真实来源词中提取并标注，不把 AI 生成词当成真实出单证据。
- `流量结构`：分开展示西柚流量入口与领星购买意向；关键词流量合计不等于 ASIN 总流量。
- `否词库`：仅列强证据候选，相关但未充分验证的词单独标为观察，不表示已经执行否词。
- `淡旺季分析`：仅使用完整自然月的产品级数据，标题和备注中明确“不是关键词级搜索量”。
