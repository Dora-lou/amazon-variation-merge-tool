# 计算、数据关联与验收规则

本文件供「飞书亚马逊销售计划」Skill 执行时查阅。**不固定列字母、行号、工作簿 token、ASIN 或售价**；先扫描现有表头、合并单元格和SKU对应关系，再将下列逻辑映射到实际单元格。尽可能用飞书原生公式，不回填静态计算值。

## 三张表的数据流

利润成本表（SKU、原始成本、费率、售价/TACOS默认值）→ 销售计划表（各月SKU售价、TACOS、销量、利润及折扣模拟）
库存表（SKU、FBA可售、FBA实际在途、待调仓、AWD可用、AWD标发在途）→ 销售计划表（库存、库存消化率和未来待售/期末余量）

实际销量来自对应站点、ASIN/MSKU、月份与数据截至日期；不得用其他月份实际销量或去年同月销量直接填充当前实际销量。

## 库存表

每个物理库存单位只能计算一次。同一SKU有多个FNSKU时先检查站点/仓库/记录维度，再无重复汇总；跨阶段状态迁移后的重复行需剔除。

- 规划总库存 = FBA可售 + FBA实际在途 + 待调仓 + AWD可用量 + AWD标发在途。
- 预计售出率 = 未来待售 / 快照时点规划总库存（当分母为0则显示待核对）。
- 预计期末库存 = 快照时点规划总库存 − 快照后的未来待售。
- 若四个月计划含快照日前的已售，未来待售 = 四个月计划总销量 − 快照日前已包含在计划中的实际已售量；不可对已经从库存中扣减的历史销量再次扣减。
- 库存位于AWD或在途且月初不能出售时，可单独写到货预期备注，不能误称当前 FBA 可售。

如果用户明确「四个月消化90%—95%」，目标区间 = 当前可规划库存 × 90%—95%；计划超出需指出风险，但不为凑库存数字夸大预计需求。

## 每个月销售计划

- 月度目标为输入值，SKU销售比例可编辑。
- 每个月所有非禁售/有计划销量的SKU比例合计 100%（零目标月份可全为0并注明）。比例合计验证须以实际单元格数值计算，不能只信格式显示100%。
- 初分配 = 月目标 × 该 SKU 比例；在允许库存/可售时点范围内将初分配转换为整数。推荐最大余数法，再把无法承接的份额转给仍有容量的SKU；所有SKU库存都无法覆盖时降低可达成目标并提示，不得隐性超卖。
- 月销量明细之和 = 月目标。日均销量 = 月SKU销量/月份自然天数（例如10月31天、11月30天、12月31天、1月31天；跨年用相应年份和月份判断）。
- 平均售价 = IFERROR(SUMPRODUCT(月销量范围, 月售价范围)/SUM(月销量范围),0)
- 销售额 = SUMPRODUCT(月销量范围, 月售价范围)
- 广告花费 = 当月销售额 × 当月TACOS
- 总月计划利润 = SUMPRODUCT(月SKU销量范围, 月SKU原价预计单件利润范围)，月预计利润率 = IFERROR(月计划利润/月销售额,0)

特别检查：SUMPRODUCT 的两个区域**行数与SKU顺序一致**，引用范围只包含商品行，不包含上方月度汇总单元格，避免循环引用。通过表头定位列，禁止套用别的文件的固定字母或行号（此前曾出现复制公式引用到自己的汇总格的问题）。

## 利润成本表：统一的重算逻辑

核心变量（逐 SKU、逐月份）：

- P = 当月正常售价（USD），q = 当月SKU计划销量，d = 生效折扣率（0—1）。
- F = 单件与售价无关的确定成本（USD）：采购、包装、头程换算、FBA配送等已确认固定项目。
- c = 平台佣金比例；a = TACOS；s = 仓储费用率；r = 退货损耗率。只有已确认/明确假设的费率可参加计算；固定仓储费/退货处理费应按固定费用处理，不可与比例费用重复扣。
- V = 其它与成交价相关的有效费率；H = 本次活动已确认的单件工具费用（例如可确认的促销服务费），缺项不伪造。

以这些费用适用于折后成交价为**明确假设**时：

- 净成交价 N = P × (1 − d)
- 单件折后预计利润 = N − F − N × (c + a + s + r + V) − H
- 折后预计总利润 = MAX(月计划 − 同月实际, 0) × 单件折后预计利润
- 单件原价预计利润 = 把 d 设为0后的同一公式
- 月度利润率 = 所有 SKU 月预计利润合计 / 所有 SKU 月计划销售额合计

上述为可配置的估算框架，并非亚马逊所有站点和促销类型的统一收费规定。若佣金、仓储、退货、TACOS 的实际计费基础不是折后销售额，应替换为有依据的实际口径；比如某些费用固定为每件金额时，记入 F 或 H。若广告预算不随售价同步变化，不应机械用折后成交价 × TACOS 代替预算。

谨防双重扣费：当已提供的「单件净利」明确已经扣除了佣金/广告/仓储时，不能再拿同一净利减去这些费用一次。数据不完整时标为「简化估算」：折后单件利润 ≈ 已知原价单件净利 − P×d。该近似忽略折扣对其他费用的影响，不能伪装成准确净利。

多个SKU价格不同，月度利润率不能简单用 SKU 费率算术平均。

## 折扣利润区：统一设置与独立覆盖

顶部：
- 测算月份：下拉选择当前计划涵盖的某个月份。
- 统一折扣率：可编辑百分比（例如10%=降10%=9折），默认为0%；是通用情景输入，并不直接修改月计划售价。

每SKU：
- 计划销量（引用所选月份）
- 实际销量（引用该月实际销量数据）
- 差值 = MAX(计划销量−实际销量,0)
- 月售价（引用该月售价）
- 原价预计单件净利（引用该月与成本表重算结果）
- 单独折扣率（手动输入，可留空）
- 生效折扣率：单独折扣率**为空**时取统一折扣；否则取该SKU值。0%是有效的SKU覆盖值，绝不等同于空白。
- 折后预计总利润（依据该 SKU 生效折扣及上述成本逻辑）
- 销售进度状态

飞书公式可参考如下形式（仅作为单格逻辑示意，使用实际列号替换）：

    =IF(ISBLANK(单SKU折扣率单元格),统一折扣率单元格,单SKU折扣率单元格)

如数据验证导致空白以空字符串保存，需针对真实单元格测试，并确保 0% 不会被误判为空。选择月份时，同步切换计划、实际、售价、原价利润；折扣对比只改情景利润，不改正式销售目标或实际售价。

月差值为0时折扣模拟利润为0；实际销量超过计划时展示「明显超前」或「超计划」状态，而不是让差值变负并制造负的折扣利润。

## 销售进度：简单、清晰

- 计划月份尚未开始：显示「未开始」。
- 当月进行中：同期计划 = 全月SKU月目标 × 当月截至数据日已过天数 ÷ 当月总天数，比较同月实际销量与同期计划。
- 已结束月份：比较整月实际销量与整月计划。
- 若同期计划为0，显示「无计划」或「暂无可比」，避免除零。
- 进度比 <70% 为「明显落后」；>130% 为「明显超前」；其余「正常」。数据更新滞后时提示「实际销量截至YYYY-MM-DD」，不可把未同步数据误判为滞销。
- 若用户希望更严格或宽松，可修改阈值；无需另建预警系统。

## 最低验收用例

1. 任一 SKU 改单月售价 → 当月加权均价、销售额、正常利润、折扣利润均联动；其他月份未指定覆盖价不受影响。
2. 改该月 SKU 销售比例与月目标 → 明细量、日均、汇总和库存余量联动；每个月SKU比例100%，整数明细数量与月目标完全一致。
3. 改 TACOS、采购成本或佣金 → 对应单件利润、月利润率及折扣情景利润联动。
4. 设置统一折扣10%，两个SKU单独填20%和0%，另一个留空 → 生效折扣分别20%、0%、10%；总利润为逐行利润和，零利润正常，负利润红色。
5. 改一个SKU本月实际销量 → 差值、折扣测算及同期进度状态联动；不改变历史月份销量。
6. 校验FBA五项库存相加与规划总库存、SKU库存上限、库存快照口径无重复。
7. 回读飞书**公式文本与计算结果**、跨表引用、合并单元格左上角公式、百分比和币种显示；所有测试输入恢复原值，无 #REF!、#VALUE!、#DIV/0! 或循环依赖。

用户要求的是可直接使用的飞书表格；不能只提交说明、Excel副本或无公式的静态截图。
