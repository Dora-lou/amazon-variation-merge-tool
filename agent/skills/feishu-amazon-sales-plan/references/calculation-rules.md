# 计算、销售预测、库存时间轴与备货验收规则

本文件供 feishu-amazon-sales-plan Skill 执行时查阅。不得固定列字母、行号、工作簿 token、ASIN 或售价。先扫描当前飞书表头、SKU映射、合并单元格和字段位置，再将逻辑映射到实际单元格。所有动态结果优先使用飞书原生公式；数据不足时留空或标记待核实，不得伪造。

## 一、数据流与执行顺序

数据流必须保持：

自身历史/当前经营数据 + 季节性 + 竞品/关键词 + SKU经营策略
→ AI三情景销售预测
→ AI原始预测 + 人工调整 + 用户确认的正式销售计划
→ 按SKU和日期模拟FBA/AWD/国内供应
→ 正常/保守生产建议、最晚下单日、分批发货和AWD调拨建议
→ 实际表现复盘。

备货计划只能读取用户确认的正式销售计划。销售预测、正式销售计划、实际销量、备货建议和已确认供应必须分别保存，不能互相覆盖。

## 二、销售预测计算原则

### 2.1 本品销量基准

- 使用本品同SKU的月度实际销量、去年同期和近30/60/90天趋势作为核心证据。
- 对比前先检查月份天数、断货、不可售、促销、价格、广告、Listing异常、变体/版本变化和数据完整性。
- 历史实际销量不修改。异常剔除或可比调整应形成独立参考值，并写明调整依据。
- 若历史销量受到断货影响，可识别被供货限制的月份，但不能无证据地把损失销量全部补回。
- SKU样本不足时，可参考高度相似SKU，但标记代理关系和较低置信度。
- 今年的利润优先策略、提价、广告收缩或减少促销可能让销量低于去年；不得机械复制去年销量，也不得无证据地用固定系数调整。

### 2.2 季节性月度比例

- 本品自身历年月度销量占比优先；今年实际趋势用于判断当前季节曲线是否偏离历史。
- 竞品仅用于辅助月度比例和市场走势。每个竞品先算其单月销量/该竞品选定期间总销量，再按月取中位数，最后将月份中位数归一化为100%。
- 竞品销量绝对值不能直接映射成本品销量规模。不得用竞品销量均值/中位数乘固定系数得出本品销量。
- 搜索量/Google Trends等季节曲线作为独立佐证，不替代本品销售曲线。
- 用户明确给出的月份比例优先。比例合计不足100%时不擅自归一化，说明未分配比例。
- 不同SKU、颜色、尺寸和版本可使用不同季节曲线；证据不足时降低置信度。

### 2.3 经营策略影响

- 每个产品/必要时每个SKU记录今年策略：保利润、平衡、冲销量或用户自定义。
- 将计划售价、历史价格响应、广告预算/TACOS、促销策略、利润目标纳入基准预测。
- 没有可靠价格弹性数据时，不得自行设置固定弹性系数；可展示区间/情景并说明假设。
- 不能把去年销量直接当作今年预测，也不能只因用户提高售价就无证据地按固定比例下调销量。

### 2.4 三情景和人工调整

- 输出保守、基准、乐观三情景；基准为AI原始预测。
- 不使用统一的固定乘数生成情景。每个情景必须说明关键假设。
- 记录每个SKU/月的AI基准预测、人工调整量/比例、调整原因和最终批准计划。
- 最终月销量为可编辑输入；月总量、SKU占比、日均、销售额和广告费等由公式联动。
- 置信度按数据完整度、可比性和趋势一致性标为高/中/低，并说明原因。

## 三、库存批次和预计可售时间

### 3.1 每批货唯一计数

每个物理库存批次只能计算一次。优先用货件编号/批次号、MSKU/FNSKU、SKU、数量、发货日期、目的仓、状态和预计到货日期建立唯一批次记录。

状态变化时从上一状态转出，再进入下一状态。例如国内→AWD在途→AWD可用→AWD调拨FBA→FBA入库→FBA可售。不得在状态迁移时把同一批货留在两个阶段重复加总。

如果无法证明两个字段互不重叠，保留原始值并标「可能重复/待核对」，不把它们同时加进规划供应。

### 3.2 FBA库存口径

- FBA可售：立即可销售，计入当前FBA可用库存。
- FBA待调仓：按用户已确认口径计入可用销售库存；保留来源字段和定义。
- FBA实际在途：按货件/SKU数量和领星预计到货日期进入未来供应时间轴。预计到货日若仅表示到仓，不等于可售；需增加产品可配置的入仓/处理时间。
- FBA入库中：按具体批次状态和预计可售时间处理；确认是否已包含于实际在途或可售，禁止重复计算。
- FBA计划入库：仅用于核对，不计入规划总库存/可靠供应，因为可能与实际在途重叠。
- FBA预留、不可售等默认排除，除非用户另行确认。

### 3.3 AWD库存口径

- AWD可用：属于FBA后备供应，不是当前FBA可售库存。调拨至FBA通常需7–14天，按SKU或实际运输数据设置；在没有更准确数据时，按7–14天区间做风险模拟，保守场景使用区间较长端。
- AWD标发在途：指国内已经发货、正在运往AWD。必须记录数量和实际发货日期；有ETA时优先使用ETA。没有ETA但发货日期和路线运输天数已知时，预计到AWD日=实际发货日+该路线运输天数，并标「估算」。
- AWD到仓后仍需加上AWD→FBA调拨时间，才能进入FBA可售时间轴。
- 缺少数量或可靠发货日期时，不作为确定供应。

### 3.4 工厂与生产供应

- 工厂库存是选填字段。用户不知道数量时保持未知，不填0，不计入可靠供应。
- 只有用户确认数量、SKU、可发货日期后，工厂现货才可作为可靠的未来供应。
- 生产中/已确认采购按预计完工日期 + 国内准备/运输 + 目的仓入仓时间计算可售日期。
- AI建议生产、计划货件和未确认采购不计入可靠供应。

## 四、库存时间轴模拟

### 4.1 时间粒度

- 销售计划按月；库存模拟至少按周，遇到临近断货或到货日时按具体日期拆分。
- 若没有周度销售预测，将月销量按当月自然日均匀分布到日/周；若有可靠周度季节曲线，则使用周度曲线。说明均摊假设。
- 按SKU独立模拟，不能跨SKU抵消。

### 4.2 FBA时间轴

对每个SKU、每个时间段：

期末FBA库存
= 期初FBA库存
+ 本期达到FBA可售日期的实际在途/入库批次
+ 本期完成的AWD→FBA调拨量
− 本期预计销售量。

期初FBA库存按用户口径计入FBA可售 + FBA待调仓。只有在对应日期可售的批次才增加库存。不能将未来货件提前加到当前库存。

预计断货日期为模拟期内FBA库存首次小于或等于0的日期；如果销售速度、ETA或批次数量不可靠，标记为估算/待核实。

### 4.3 AWD时间轴

期末AWD库存
= 期初AWD可用库存
+ 本期到达且完成AWD入库的国内在途批次
− 本期已安排/实际调拨至FBA的数量。

AWD调拨量在AWD时间轴中扣除，并在预计FBA可售日期加入FBA时间轴。不得同时保留在AWD期末库存和FBA库存。

### 4.4 FBA目标覆盖与调拨触发

- 用户的正常FBA覆盖参考为约1–2个月，但按产品季节、未来销量、调拨周期、销量波动和运输风险动态调整。
- FBA目标库存 = 对应目标覆盖期内的SKU预计销量；目标覆盖天数是可编辑输入，必须说明本次选择理由。
- AWD不再单独套用固定1–2个月覆盖目标；AWD缓冲量由FBA未来需求、7–14天调拨周期、下一批国内货到AWD的日期和安全缓冲共同决定。
- 预计FBA库存到AWD调拨可售日时若低于目标/安全库存，应提前触发调拨。
- 建议调拨量 = MAX(0, 目标FBA库存 − 调拨到达日预计FBA库存)，并受AWD可用库存限制。
- 调拨到达日预计FBA库存需包含到达日前的计划销量和所有已确认FBA到货/调拨，不得只看当前库存。
- 若AWD自动调拨，先读取自动规则和在途量，不重复生成手动建议。读取不到时标「自动规则待核实」，不伪造自动调拨数量。

## 五、采购交期和最晚下单日期

### 5.1 可配置参数

每个产品/必要时SKU、路线和目的仓可单独配置：
- 采购/生产天数
- 国内备货/送港/等船天数
- 头程运输天数
- FBA或AWD入仓处理天数
- AWD→FBA调拨天数（通常7–14天）
- 安全缓冲天数
- 工厂是否有现货
- 目的地（美西/美东或其他）
- 是否允许一次生产后分批发货、MOQ、工厂暂存条件等选填备注。

若用户给出完整总交期，则直接用该总交期；若提供分段天数，则按阶段求和，不能把已经包含在总交期中的环节重复加算。工厂有已确认可发货现货时，生产时间设为0，仅计算后续准备/运输/入仓。

### 5.2 默认估计值

仅在用户没有提供产品参数时，可作为待确认初始参考：
- 无现货生产约30天；
- 国内准备/等船约7天；
- 美西海运约45天；
- 美东海运约60天；
- 入仓处理约7天。

示例：30+7+45+7=89天（美西）；30+7+60+7=104天（美东）。用户给出的产品专属周期优先，例如采购45天、头程约38天、入仓7天。所有默认值必须标为估算，用户确认后才可作为正式倒推参数。

### 5.3 日期倒推

最晚下单日 = 目标仓库可售日期 − 完整交期。

如果分批到货，分别按每批的目的仓、路线和交期倒推。若最晚下单日已过，提示交期风险并计算最早可能可售日，不得声称仍能按时到仓。

FBA实际在途优先使用领星货件预计到货日。若该日期代表到仓而不是可售，追加可配置入仓处理天数。AWD无ETA时，仅在实际发货日期和路线运输时间已知时推算，并标明估算范围。

## 六、生产量与分批发货建议

### 6.1 基本原则

- 生产建议基于用户确认的基准销售计划，分别计算正常方案和保守方案。
- 乐观预测用于判断额外供应空间和断货风险，不作为默认生产承诺。
- 用户认可的初步原则：交期内预计销量 + 交期后约一个月预计销量，再扣除对应时间可用的可靠供应并考虑目标库存缓冲。
- 该原则只作为检查基准。最终必须用库存时间轴验证各SKU、各仓库在每个关键日期是否断货或积压。
- 不得把FBA、AWD、工厂和在途数量简单相加后当成当前可用库存。

### 6.2 时间轴缺口

对每个SKU和关键日期，计算：

累计需求(t) = 从模拟起点到日期t的累计销售预测。

可在日期t前转化为FBA可售的供应(t) = 截至日期t已在FBA可售/按用户口径可用的库存 + 日期t前可售的FBA实际在途/入库批次 + 日期t前已完成AWD调拨并可售的数量。AWD现有库存、国内发往AWD的在途货，只有在考虑AWD入仓和AWD→FBA调拨周期后能赶在t日前转为FBA可售，才可计入该日期的可转化供应。

目标缓冲(t) = 日期t之后用户设定覆盖期内的SKU预计销量，或用户明确设定的库存缓冲。

时间点供应缺口(t)
= MAX(0, 累计需求(t) + 目标缓冲(t) − 可在日期t前转化为FBA可售的供应(t))。

注意：可转化供应已包含截至t日的初始库存和可靠到货批次，不得再次减去同一批「已确认新增供应」。FBA与AWD库存仍须分别维护时间轴；AWD不能提前当作FBA可售。检查规划期内所有关键日期，找出最早缺货点和最大缺口。新生产/发货的数量与日期应能填补相应缺口；不能只看规划期末总量。

### 6.3 生产建议

- 正常方案：基于基准销售计划和正常供应交期。
- 保守方案：基于保守销量情景、相同已确认供应和更谨慎的需求假设。
- 两方案分别显示需求、可靠供应、目标缓冲、建议新增生产量、预计到仓时间、旺季结束余量和淡季自然消化。
- 生产量按SKU独立计算，考虑MOQ/包装倍数等用户提供限制；若MOQ导致生产后超过需求，明确展示超出量，不隐藏。
- 规划周期根据产品季节性和交期确定，不固定为3个月或整个旺季。
- 若到货时旺季接近结束，检查剩余旺季需求、淡季自然销量、下一旺季时间和持有库存风险；没有足够需求证据时，不建议为了短期缺口盲目生产。
- 对季节性库存，检查用户设定的旺季消化目标（例如至少95%）；同时估计合理的淡季结转库存，不得为达成百分比自动建议无利润折扣。

### 6.4 生产批次与发货批次分离

- 允许一次性生产总量后分批发货。
- 分开记录：建议生产量、用户确认生产量、实际生产完成量、工厂已确认待发量、计划发货量、已确认发货量、实际发货量。
- 分批发货表至少包括：SKU、批次、计划发货日期、目的仓（FBA/AWD）、数量、路线、预计到货日、预计可售日、状态和决策依据。
- 状态分为AI建议、用户已确认、实际已发出、已入仓/可售；只有实际发出或可靠确认的供应才能按相应时间计入供应模拟。
- 后续批次在发货前重新评估实际销量、市场预警、库存和旺季剩余时间；销量走弱时提醒暂缓未执行批次，不自动取消已确认事项。

## 七、销售计划与公式

### 7.1 月度SKU输入和汇总

- 默认每个SKU每月最终计划销量是可编辑整数输入。
- 每月总单量 = 当月所有SKU月销量之和。
- SKU月销售比例 = SKU当月销量 / 当月SKU销量合计；是结果校验，不反向覆盖月销量。
- 日均销量 = SKU月销量 / 当月自然日数。
- 月销售额 = SUMPRODUCT(SKU月销量区域, SKU月售价区域)。
- 加权平均售价 = IFERROR(月销售额 / SUM(SKU月销量区域), 0)。
- 广告花费 = 月销售额 × 当月TACOS。
- 如用户指定规划基数和月度比例，可用于生成初始月目标；确认后，最终SKU月销量仍保持可编辑，不允许比例公式覆盖用户修改。
- 公式引用区域行数和SKU顺序必须一致，不能把顶部汇总格包含进SUMPRODUCT造成循环引用。

### 7.2 实际、差值和补量

- 只有已有实际销量的月份才显示实际销量输入列；未来月份保持空白，不得以空白伪装为实际0。
- 差值 = 实际销量 − 原计划销量。未达计划为负数，超计划为正数。
- 待补量 = MAX(原计划销量 − 实际销量, 0)，与差值分开。
- 若用户决定把前期未完成量分摊到后续月份，按用户指定的后续月比例/原计划权重分配，并保留原计划与调整后执行量。当前库存快照已扣除历史销量时，不得重复扣减历史销量。
- 默认不自动把所有未完成量加到未来计划；先判断未完成原因和未来季节需求。
- 用户明确要求按后续月份原计划比例分摊时：
  1. 保留历史月份原计划、实际销量、差值和待补量。
  2. 只在未结束的后续月份之间分摊；已结束月份不参与。
  3. 后续月权重 = 该月原计划目标比例 / 所有剩余后续月份原计划目标比例之和。
  4. 目标月追补量 = ROUND(可分摊量 × 目标月权重, 0)。
  5. 舍入余数分配给权重较大且仍有SKU库存承接能力的月份；不得无条件全部塞给最后一个月。
  6. 若SKU库存或季节需求不足以承接，显示未追回量及原因，不跨SKU抵消。
  7. 当前库存快照已反映此前实际销量时，只扣除快照日期之后的调整后执行量。
  8. 原计划月目标、调整后执行目标和实际销量必须分开标识；不得把追补量重复计入总计划。
- 追补建议与正式计划分开；用户确认后才进入最终计划。

### 7.3 利润成本

设：
- P = 当月正常售价（USD）
- F = 单件已确认固定成本（采购、包装、头程、FBA配送等）
- c = 平台佣金率
- a = TACOS
- s = 仓储费用率
- r = 退货损耗率
- V = 其他已确认的随成交价变化费用率

原价单件预计利润的透明估算：
单件预计利润 = P − F − P×c − P×a − P×s − F×r − P×V。

其中退货损耗默认按固定成本×退货率估算，只有在该假设适用时才使用；如果用户提供实际退货费用口径，按实际口径替换。缺失费率不伪造。若用户提供的单件净利已经扣除某项费用，不得重复扣除。

月度利润金额 = SUMPRODUCT(SKU月销量, SKU单件预计利润)。
月度利润率 = IFERROR(月度利润金额 / 月销售额, 0)。

SKU利润逐行计算；不得复制父体利润或对SKU利润率做普通平均。

### 7.4 折扣利润测算

- 折扣区使用一个「测算月份」下拉和一个「统一折扣率」输入；一次只展示所选月份。
- 每个SKU可设置单独折扣率。单独折扣率为空时继承统一折扣率；填0%表示明确不打折，公式必须区分空白和0。
- 折后成交价 = 原售价 × (1−生效折扣率)。
- 有完整成本拆分时，按折后成交价重算佣金、广告及其他随成交价变化的费用，再扣固定成本和已确认的其他费用。
- 仅有可信原价单件净利时，可使用简化估算：折后单件利润≈原价单件净利−原售价×折扣率；明确标「简化测算」，不得称为精确净利。
- 差值仍为实际销量−计划销量；折扣情景待完成件数单独为MAX(计划销量−实际销量,0)。未来月份无实际记录时显示空白/未开始。
- 折后预计总利润 = 待完成件数 × 折后单件预计利润。只汇总所选月份SKU结果；负利润标红。
- 折扣测算不修改正式售价、实际销量、广告预算或后台促销。

### 7.5 销售进度

- 未来月份显示「未开始」。
- 当月进行中：同期计划 = 全月计划 × 已过自然日/当月自然日；与截至数据日实际销量比较。
- 已结束月份与整月计划比较。
- 同期实际/理论低于70%可标明显落后，高于130%可标明显超前；阈值可编辑。数据同步滞后时标明实际销量截至日期。
- 若同期计划为0，显示「无计划/暂无可比」，避免除零。

## 八、格式和飞书公式验收

- 复用最近一次用户认可的销售计划版式。月份横向分组，顶部汇总顺序为大类、小类、平均售价、总单量、预计利润率、TACOS、销售额、广告花费、备注；大类/小类未提供时留空。
- 月份标题亮黄色底、黑色加粗；左侧汇总标签淡粉；汇总结果浅蓝绿色；输入项与公式结果区分。
- 利润测算固定配色：成本/输入浅蓝 #EAF3FB；费率输入浅黄 #FFF7DF；公式结果浅绿 #E2F0D9；净利/利润率重点中绿 #A9D18E；表头浅蓝 #D9EAF7；说明区浅灰 #F6F8FA；售价列浅橙 #FCE4D6、输入蓝字 #1673B8。所有文字用深色，禁止浅底白字。
- 售价字段命名「售价 USD」，不得用「划线价」代替。售价、销售额和利润两位小数；费率/利润率两位百分比；销售比例、竞品月占比和消化率整数百分比；销量/库存/差值整数；日均一位小数。
- 中文文本用UTF-8无BOM写入。写入后从飞书回读单元格实际文本，检查替换字符、锟斤拷和明显乱码。
- 修改表格前识别输入格、公式格和合并区域；插删行列后重查所有跨表公式、复制范围和折扣区引用。
- 至少验证：SKU月销量改动会联动月合计/比例/日均/销售额/广告费/利润/库存；售价和TACOS改动会联动利润；差值符号正确；追补量不重复；库存批次不重复；交期倒推正确；AWD调拨扣减和FBA到货增加同步；测试输入恢复原值；无循环引用、#REF!、#VALUE!、#DIV/0!。
