# 销售计划五表模板合约

版本：1.1  
来源：用户上传并认可的《加热垫2.0销售计划-最新.xlsx》  
目标：飞书原生电子表格  
本文件与 `schema/template-contract.json` 是销售计划 Skill 的唯一结构标准。


## 0. 合同执行级别（强制）

本合同不是参考建议，而是不可变的验收标准。Codex 只负责读取业务数据、计算结果并填充规定的数据区，不负责重新设计表格。

- 不得自由改写表头、字段顺序、说明文字、公式、布局、颜色、字体、边框、数字格式、合并单元格、冻结窗格、数据验证或条件格式。
- 唯一允许的结构变化是：按工作台输入动态增加/减少连续月份模块；按真实数据量扩展 SKU 行和合格竞品行。扩展时必须复制原模板对应行/模块的格式与公式模式。
- 无法复刻某项格式或公式时必须停止写入并报告，不得用“相近”的格式替代后声称完成。
- 母版只需由用户提供一次，已固化的合同长期随 Skill 使用；每次任务只使用工作台填写的 ASIN、站点、月份、消化目标、知识库/表格、操作模式和补充要求。
- 任何缺失数据必须留空或标记待核实，不得继承母版示例产品数据，也不得为填满表格而编造。
- 任何验收失败都不得交付为完成状态。

## 1. 不可变规则

每次生成必须且只能有以下五张表，名称和顺序完全固定：

1. 销售计划
2. 库存统计
3. 利润测算
4. 竞对分析
5. 月度复盘与补量折扣

不因数据缺失而删表：
- 竞品数据缺失：保留「竞对分析」，样本区留空，汇总公式安全返回空白。
- 实际销量缺失：保留「月度复盘与补量折扣」，实际销量留空，状态显示「未录实际销量」。

不得新增第六张表或任何其他工作表；不得删除、重命名、调换五张表。不得新增或删除模板字段、列、标题区、备注区、图表或看板。超出五张表字段承载范围的分析，写在 Codex 最终执行报告中。

更新已有表时，如发现用户原有的额外 Sheet 或非模板结构，不得擅自删除可能包含用户数据的内容；停止结构性删除并报告冲突。新建表必须严格为五张。

## 2. 动态月份

- 规划月份由工作台开始月份和结束月份决定，首尾月份均包含，按自然月连续生成。
- 不固定四个月。规划多少期，就生成多少期。
- 「销售计划」按月横向重复模板模块。实际销量已取得的月份使用含实际模块；没有实际销量数据的月份使用计划模块。
- 含实际模块六列，顺序固定：销售比例、日均、原计划月销量、实际销量、差值（实际−计划）、售价 USD。
- 计划模块四列，顺序固定：销售比例、日均、月销量、售价 USD。
- 每个月均保留模板规定的顶部汇总行、月目标规划比例、月份标题、合并区域和 SKU 行样式。
- 「月度复盘与补量折扣」测算月份选项必须动态覆盖全部规划月份。
- 「竞对分析」使用四个月连续窗口，四个月份标题根据实际数据窗口动态命名；不得残留母版示例月份。

## 3. 动态行

- 销售计划、库存统计、利润测算、月度复盘均以同一 SKU 顺序生成数据行。
- SKU 展示槽位至少六行；少于六个 SKU 时多余行留空；超过六个 SKU 时只扩展数据行，复制对应样式、公式和边框。
- 竞对分析至少保留二十行样本展示位；实际合格竞品多于二十个时扩展数据行。少于二十个时如实显示实际样本数，空余行留空，不得凑数。
- 扩展行不得改变表头、列顺序、总计行逻辑、汇总区和固定 Sheet 结构。

## 5. 公式合同

以下公式描述的是模板逻辑。实际列位置必须按动态月份模块和 SKU 行映射生成，不能照搬母版固定列号。

### 销售计划
- 含实际月份差值 = 实际销量 − 原计划月销量。
- SKU月销售比例 = SKU月销量 / 当月SKU月销量合计。
- 日均 = SKU月销量 / 当月自然日数。
- 平均售价 = 当月销售额 / 当月总单量；用 IFERROR 防止除零。
- 销售额 = SUMPRODUCT(当月SKU月销量, 当月SKU售价)。
- 广告花费 = 销售额 × 当月TACOS。
- 后续月份SKU月销量 = ROUND(SKU规划总库存 × 工作台库存消化目标 × 当月月目标规划比例, 0)。
- 规划目标比例是模板规定的可编辑输入；公式输出格不得改为手输。

### 库存统计
- 规划总库存 = FBA可售 + FBA待调仓 + FBA入库中 + FBA实际在途 + FBA计划入库 + AWD可用 + AWD标发在途。
- 规划目标 = ROUND(规划总库存 × 工作台库存消化目标, 0)。
- 后续计划量引用销售计划中库存快照日之后的计划月份。
- 预计余量 = 规划总库存 − 后续计划量。
- 库存消化率 = 后续计划量 / 规划总库存。
- 库存检查按模板状态逻辑生成；缺失值不得当作0。

说明：库存统计表的规划总库存按母版口径汇总七个字段；在底层日期时间轴中仍须识别物理批次状态迁移和重复字段，防止同一批货被重复计入可靠供应。

### 利润测算
- 固定成本 = IF(COUNT(产品成本, FBA配送费, 其他固定成本)=3, 三项合计, 空白)。
- 公式估算单件净利 = 售价 − 固定成本 − 售价×(平台佣金率+其他售价计提率+TACOS+仓储率) − 固定成本×退货率。
- 公式估算单件利润率 = 单件净利 / 售价。
- 阶段广告费 = 对应月份 SKU 计划销量 × 售价 × 默认TACOS。
- 关键成本/费率缺失时留空并标「待补成本」，不复制其他 SKU 数据。

### 竞对分析
- 单品四月合计 = 四个月销量之和。
- 单品月份占比 = 该竞品该月销量 / 该竞品四月合计。
- 月份中位数 = 对各合格竞品的该月占比取 MEDIAN。
- 四月中位数归一化 = 该月中位数 / 四个月中位数之和。
- 未来三月建议比例 = 后三个月中位数 / 后三个月中位数之和。
- 没有有效样本时汇总单元格留空，不返回 #DIV/0!。

### 月度复盘与补量折扣
- 差值 = 实际销量 − 所选月计划销量。
- 待完成目标量 = MAX(所选月计划销量 − 实际销量, 0)；实际销量为空时结果保持空白。
- 折后售价 = 售价 × (1 − 生效折扣率)。
- 折后单件净利按利润测算表的成本和费率重新计算。
- 折后预计总利润 = 待完成目标量 × 折后单件净利。
- 没有实际销量时显示「未录实际销量」，实际销量不得填0。

## 6. 样式与布局

- 全表字体：等线。
- 月份标题：亮黄 `#FFE84A`，黑色加粗。
- 左侧汇总标签：淡粉 `#F9E3EC`。
- 汇总结果：浅青绿 `#D9F0EC`。
- 输入区：浅蓝 `#EAF3FB`；费率输入浅黄 `#FFF7DF`。
- 普通公式结果：浅绿 `#E2F0D9`；净利/利润率重点：中绿 `#A9D18E`。
- 表头：浅蓝 `#D9EAF7`。
- 说明区：浅灰 `#F6F8FA`。
- 售价列：浅橙 `#FCE4D6`；输入蓝字 `#1673B8`。
- 保留母版边框、对齐、数字格式、合并区域、冻结窗格、行高和列宽。具体尺寸和固定区域见 JSON 合约。
- 不得擅自加图表、装饰、标题、空白说明区或额外格式。

## 7. 母版数据隔离

母版只提供结构与公式模式。每次必须重新获取本次产品的 ASIN、SKU、历史销量、实际销量、库存、价格、成本、TACOS、竞品、日期和说明。任何缺失项留空或标待核实。禁止将母版示例 ASIN、SKU、产品名称、销量、库存、价格、成本、竞品或月份带入新产品。

## 8. 验收

- Sheet 名称和顺序严格等于五张固定表。
- 所有表头与列序匹配合约。
- 销售计划月份数量与工作台规划月份数一致。
- 每个月的模块宽度为4列或6列，且表头与实际数据状态匹配。
- SKU 行在四张相关表中一一对应；无错位、无额外列。
- 竞对无数据时 Sheet 保留，汇总无除零错误。
- 月度复盘无实际销量时 Sheet 保留，实际销量空白且状态正确。
- 公式、格式、合并、冻结区域和数据验证按模板保留。
- 不存在 #REF!、#VALUE!、#DIV/0! 等错误。
- 不含母版其他产品的示例数据。
- 完成后回读飞书原生表格；有导出文件时运行 `scripts/validate_output.py`。校验未通过不得报告成功。
